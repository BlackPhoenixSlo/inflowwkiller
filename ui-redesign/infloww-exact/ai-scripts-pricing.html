Advanced escalation math · send caps · the raw script pack

Escalation math

Next ask = his last paid price × 1.75, never above 3× the largest single unlock he has ever made. A fan who has never paid is never asked more than $59.

Per-PPV send caps

0 = no cap. The ladder's own pacing — one climb per buy, max 8 asks per fan per day — usually does the throttling for you.

Script pack — her canned lines

One line is picked at random per moment; {name} and {price} fill in automatically. An edited line replaces the shipped set for that slot. Six slots are wired into the engine today — escalate, after a buy, discount resend, soft "I'm broke", aftercare and just-wants-to-talk. The rest are marked never sent: they save fine, but no code path renders them, so editing one changes nothing a fan will read.
These knobs move real money. The defaults match what the engine ships with — change them only if you know why.
